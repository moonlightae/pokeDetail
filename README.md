# Speed Dex

포켓몬 스피드 범위 비교 도구입니다. Vite와 TypeScript를 사용하며, 실행 중 데이터는 로컬 JSON에서 읽습니다.

## 코드 구조

| 파일 | 책임 |
| --- | --- |
| `src/index.ts` | 앱 상태, DOM 렌더링, 사용자 이벤트 연결 |
| `src/app.html` | 초기 화면 HTML. Vite의 `?raw` import로 읽습니다. |
| `src/pokemon.ts` | 데이터 타입, 도감 로딩, 검색 인덱스와 이름 검색 |
| `src/calculator.ts` | 스피드 실능과 최저/최속 범위 계산 |
| `src/comparison.ts` | 동일 종족값의 행 병합, 메가/특성 비교 데이터, 추월선 계산 |
| `src/webmcp.ts` | WebMCP 등록, 입력 검증, 비교 설정 콜백 호출 |
| `src/styles.css` | 화면 스타일과 반응형 배치 |
| `scripts/sync-pokemon-data.mjs` | 외부 데이터를 수집하여 `public/data/pokemon.json` 생성 |

실행 흐름: `app.html` 표시 → `pokemon.ts`에서 도감 로딩 → `index.ts`에서 상태 갱신 → `comparison.ts`와 `calculator.ts`에서 비교 계산 → DOM 렌더링.

계산·검색 모듈은 DOM이나 앱 전역 상태에 의존하지 않습니다. WebMCP는 같은 검색 인덱스를 사용하고 `index.ts`의 비교 설정 함수를 호출합니다. 화면 상태는 `index.ts`에 유지하며 별도 상태 관리 라이브러리는 사용하지 않습니다.

## 명령

- `npm ci`: 의존성 설치
- `npm run dev`: 개발 서버
- `npm test`: DOM 없는 로직 회귀 검사
- `npm run build`: TypeScript 검사 및 `dist` 빌드
- `npm run preview`: 빌드 결과를 로컬에서 제공
- `npm run sync:data`: 외부 데이터 갱신. 리팩터링 검증에는 필요하지 않습니다.

## 사용자 QA 목록

이번 작업은 배포 전 구조 정리입니다. 사용자 요청에 따라 로컬 브라우저 QA를 수행했습니다. 배포 환경에서는 아래 목록으로 추가 확인하실 수 있습니다.

직접 확인한 항목: 변경 안내 문구, 초기 도감 표시, 영어·도감 번호 검색과 중복 안내, 삭제·재추가, EV/성격과 레벨 변경, 트릭룸, TOP 20/50/100 전환·해제 및 수동 선택 유지, ArrowDown/Escape, WebMCP 비교 설정, 모바일 390px·데스크톱 1280px 배치입니다. 확인한 화면에서 페이지 가로 넘침이나 브라우저 경고·오류는 발견하지 못했습니다.

운영 배포는 GitHub `master` 브랜치와 연결된 Vercel에서 진행됩니다. `vercel.json`의 빌드 명령은 회귀 검사 후 빌드를 실행합니다. 공유 주소는 https://poke-detail.vercel.app/ 입니다. 도감과 픽률은 표시된 갱신일 기준의 스냅샷이며 실시간 데이터가 아닙니다.

- [ ] 초기 4마리와 도감/픽률 갱신 정보가 표시되는지 확인해 주세요.
- [ ] 한국어·영어·도감 번호 검색, 추천 선택, Enter 추가가 동작하는지 확인해 주세요.
- [ ] 중복 선택과 일반 비교 6마리 제한 안내, 삭제 후 재추가가 동작하는지 확인해 주세요.
- [ ] TOP 20/50/100 전환 및 해제 시 검색으로 고정한 포켓몬이 유지되는지 확인해 주세요.
- [ ] 레벨 50/100 전환 시 범위와 추월선이 함께 갱신되는지 확인해 주세요. 피카츄 범위는 각각 99~156, 194~308입니다.
- [ ] 같은 종족값의 일반/메가 폼이 한 행에 표시되고 특성 발동 범위가 나타나는지 확인해 주세요.
- [ ] 포켓몬 클릭 후 EV 0~32, 성격 변경 시 현재 실능·앞뒤 최대 5마리·동속 목록이 갱신되는지 확인해 주세요.
- [ ] 트릭룸 전환 시 축과 추월 판단이 반전되고, 선택한 포켓몬 삭제 시 추월선이 닫히는지 확인해 주세요.
- [ ] 검색 추천에 ArrowDown으로 진입하고 Escape로 닫을 수 있으며, 포켓몬을 Enter/Space로 선택할 수 있는지 확인해 주세요.
- [ ] 모바일 배치, 차트 가로 스크롤, 이미지가 정상적으로 보이는지 확인해 주세요.
- [ ] WebMCP 지원 환경에서 이름과 레벨 설정이 화면에 반영되는지 확인해 주세요.

문제 보고 시 사용한 포켓몬, 레벨, 프리셋, EV/성격, 트릭룸 여부와 재현 순서를 함께 알려 주세요.
